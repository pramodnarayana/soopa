# Soopa UCP API

## Description

The Soopa Unified Control Plane (UCP) API. This service is responsible for managing tenant provisioning, API keys, and orchestrating interactions between the control plane and data planes across various microservices.

## Project setup

```bash
$ pnpm install
```

## Compile and run the project

```bash
# development
$ pnpm run start

# watch mode
$ pnpm run start:dev

# production mode
$ pnpm run start:prod
```

## Run tests

```bash
# unit tests
$ pnpm run test

# e2e tests
$ pnpm run test:e2e

# test coverage
$ pnpm run test:cov
```
