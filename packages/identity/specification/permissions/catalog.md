# Permission Catalog

Permissions are namespaced by product capability.

| Permission | Description |
| --- | --- |
| `identity:users:read` | Read user profiles and memberships. |
| `identity:users:write` | Manage users and memberships. |
| `identity:roles:assign` | Assign roles to users or service accounts. |
| `integration:connections:read` | Read integration connection settings. |
| `integration:connections:write` | Manage integration connection settings. |
| `edi:transactions:read` | Read EDI transaction state. |
| `edi:transactions:write` | Create or mutate EDI transaction state. |
| `idp:settings:read` | Read IDP configuration. |
| `idp:settings:write` | Manage IDP configuration. |
