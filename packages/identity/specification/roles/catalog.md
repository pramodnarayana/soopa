# Role Catalog

Roles are coarse-grained job functions. Permissions remain the source of truth
for sensitive decisions.

| Role | Description |
| --- | --- |
| `soopa.owner` | Full tenant administration. |
| `soopa.admin` | Tenant operations and user management. |
| `soopa.operator` | Day-to-day integration and EDI operations. |
| `soopa.viewer` | Read-only operational access. |
| `soopa.service` | Machine-to-machine access. |
